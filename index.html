GitHub Pages Image URL Demo

Sample image path inside the repo:

assets/images/sample.svg

Once this repo is pushed and GitHub Pages is enabled, the public URL will be:

https://YOUR_USERNAME.github.io/REPO_NAME/assets/images/sample.svg

Replace YOUR_USERNAME and REPO_NAME with your actual GitHub username and repository name.
